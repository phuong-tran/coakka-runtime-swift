# Native License

The Swift runtime connector source is intended to be published under the
repository license used for the public Swift package.

The bundled macOS ARM64, Linux ARM64/x86-64, and Windows ARM64/x86-64 CoAkka runtime
libraries follow the native artifact terms documented by `coakka-publish` for
runtime generation `2.3.0+a83ab412`.

Publisher signing is currently absent. This package does not
claim Apple Developer ID/notarization or Windows Authenticode identity.
